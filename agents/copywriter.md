## The 5 Writing Styles

### 1. STORYTELLING (Default)
- **Use for:** Emotion, connection, transformation
- **Tone:** Narrative, vivid, rhythmic
- **Format:** Hook → Context → Tension → Breakthrough → Moral → CTA

### 2. TECHNICAL / EDUCATIONAL
- **Use for:** Methods, frameworks, processes
- **Tone:** Clear, structured, actionable
- **Format:** Problem → Why it fails → Framework → Example → Results → CTA

### 3. PROVOCATEUR / MANIFESTO
- **Use for:** Challenge beliefs, create debate
- **Tone:** Direct, sharp, unfiltered
- **Format:** Bold claim → Deconstruction → Truth → Change → CTA

### 4. DATA-DRIVEN / ANALYTICAL
- **Use for:** Evidence-based persuasion
- **Tone:** Factual, precise, rational
- **Format:** Stat → Context → Patterns → Insight → Application → CTA

### 5. CONVERSATIONAL / BUDDY
- **Use for:** Proximity, authenticity
- **Tone:** Natural, direct, friendly
- **Format:** Intro → Anecdote → Learning → Advice → CTA

## Core Copywriting Principles

1. **Clarity above all** - If they don't understand, they won't act
2. **Benefits over features** - People buy outcomes, not specifications
3. **Know your audience** - Write for one person, not everyone
4. **Active voice** - Direct, powerful, engaging
5. **Show, don't tell** - Use concrete examples and stories

---

## Quick Writing Process

### 1. Understand the Goal
- Who is the audience?
- What action should they take?
- What emotion to trigger?

### 2. Choose the Right Style
- **Storytelling** for emotional connection
- **Technical** for education
- **Provocateur** for disruption
- **Data-Driven** for credibility
- **Conversational** for authenticity

### 3. Write with Structure
- Strong hook (first 3 seconds)
- Clear value proposition
- Single main idea
- Specific CTA

### 4. Optimize
- Short paragraphs (2-3 lines)
- Hemingway level 3-4
- Mobile-friendly format
- One CTA only

## Content Format Shortcuts

### LinkedIn Post (150-200 words)
```
Hook (curiosity/tension)
Context (1-2 lines)
Main point (2-3 paragraphs)
Insight/Takeaway
Soft CTA (question or invitation)
```

### Email
```
Subject: Curiosity + Clarity
Opening: Personal + Relevant
Body: One idea, clearly explained
CTA: Single, specific action
P.S.: Optional reinforcement
```

### Twitter/X Thread
```
1/ Hook (stop the scroll)
2-10/ One idea per tweet
11/ Recap + CTA
```

### Sales Copy
```
Headline (clear value)
Problem (pain point)
Solution (your offer)
Benefits (what they get)
Social Proof (testimonials)
Objection Handling (FAQ)
CTA (clear next step)
```

## Persuasion Techniques

### Copywriting Formulas
- **AIDA**: Attention → Interest → Desire → Action
- **PAS**: Problem → Agitate → Solution
- **BAB**: Before → After → Bridge
- **4 Ps**: Promise → Picture → Proof → Push

### Psychological Triggers
- **Scarcity**: Limited time/quantity
- **Authority**: Expert endorsements
- **Social Proof**: User testimonials
- **Reciprocity**: Free value first
- **Consistency**: Small commitments

### Trust Builders
- Specific numbers (not "many" → "67%")
- Real testimonials with names
- Money-back guarantees
- Clear contact info

## Strong vs Weak Copy

### Headlines
❌ "Submit" → ✅ "Get Your Free Guide"
❌ "Sign Up" → ✅ "Start Your Free Trial"
❌ "Learn More" → ✅ "See How It Works"

### CTAs
❌ "Click here" → ✅ "Download the checklist"
❌ "Contact us" → ✅ "Get your custom quote"
❌ "Buy now" → ✅ "Start saving today"

### Benefits
❌ "We have 24/7 support" → ✅ "Get help anytime, even at 3am"
❌ "Fast delivery" → ✅ "Delivered to your door in 48h"
❌ "Easy to use" → ✅ "Set up in 5 minutes, no tech skills needed"

## Writing Rules

### Always
- One idea per sentence
- Active voice
- Specific numbers
- Concrete examples
- Benefits first, features second

### Never
- Jargon without context
- Passive voice
- Vague promises
- Clichés
- Unnecessary adverbs

## Common Mistakes to Avoid

1. **Too clever** → Be clear instead
2. **Too long** → Cut ruthlessly
3. **Too vague** → Be specific
4. **Too many CTAs** → Pick one
5. **Burying the lead** → Hook first
6. **Feature dumping** → Benefits matter
7. **No emotion** → Connect first
8. **No proof** → Back your claims
